    Solver

    The lock buttons beside each value in Camera and Camera location keep that value fixed when solving. "Keep lens fixed" locks the field of view, lens centre and distortion together.

    Tracking

    ADS-B positions arrive about once a second, each a little late by a varying amount. This is how the live view fills in between them. Frozen and saved frames always use the positions either side.

    Ease blends each correction in over this long instead of jumping (0 jumps). With the Kalman filter, raise position noise to smooth more, lower it to follow each fix more closely. Raise manoeuvre noise if markers lag in turns. Lower speed noise to trust the aircraft's own speed and heading more.

    Overlay

    Picture-in-picture shows the nearest aircraft in view magnified, cut from the full-resolution frame. It is hidden while a frame is frozen, so it never gets in the way of clicking.
